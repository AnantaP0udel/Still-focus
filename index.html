Setup instructions
  1. Open the and create an app for your personal use. Select Web API.
  2. In its settings, add this exact Redirect URI:
    http://127.0.0.1:17844/callback
  3. Copy its Client ID into the field below. No client secret is needed.
  4. Click Connect Spotify and approve the playback permissions in your browser. If Spotify denies access, check Premium eligibility and the app’s User Management.

Your preferences

Alarms play for about 5 seconds, including while Still is minimized. With automatic intervals off, the alarm means your next interval is ready; click Resume to start it. Windows volume and mute still apply.

Closing Still pauses your timer. Reopening restores it. Pin keeps the main window above other apps; the mini timer is always pinned.

Connect your distraction shield

Install the included extension in Microsoft Edge or Chrome, then pair it with this app.

  1. Open your browser’s Extensions page and enable Developer mode.
  2. Choose Load unpacked and select the extension folder opened below.
  3. Click the Still extension icon. Paste this pairing key and select Connect.

Blocks new page loads in browsers where the extension is installed. Changes sync within 30 seconds. Breaks, pauses, and closing the app release the block. Already-open pages must be reloaded; this does not block other apps or browsers.
